STEP 1: UPLOAD PROJECT FILES
─────────────────────────────

[ ] Option A - File Manager:
    1. Go to cPanel → File Manager
    2. Open public_html folder
    3. Create folder: bionic-computer
    4. Upload all project files (drag & drop)
    
[ ] Option B - FTP:
    1. Get FTP credentials from cPanel
    2. Use FileZilla or similar
    3. Upload to: public_html/bionic-computer
    
[ ] Option C - SSH:
    1. Connect via SSH
    2. cd ~/public_html/bionic-computer
    3. Upload files

STEP 2: INSTALL DEPENDENCIES
────────────────────────────

[ ] Via SSH or cPanel Terminal:

TROUBLESHOOTING:

❌ "Module not found" error?
  → SSH: cd ~/public_html/bionic-computer && npm install
  → Try again

❌ "App not starting" in cPanel?
  → Check View Logs
  → Look for error messages
  → Make sure API key is set

❌ "Domain not loading"?
  → Wait 24 hours for DNS
  → Check domain points to public_html/bionic-computer
  → Clear browser cache

❌ "Chatbot not responding"?
  → Add payment method to Anthropic
  → Verify API key in Environment Variables
  → Check cPanel logs
