NGINX REVERSE PROXY CONFIG (if needed):

Create file: /etc/nginx/sites-available/bioniccomputer

server {
    listen 80;
    server_name bioniccomputer.com.pk www.bioniccomputer.com.pk;
    
    location / {
        proxy_pass http://localhost:3000;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection 'upgrade';
        proxy_set_header Host $host;
        proxy_cache_bypass $http_upgrade;
    }
}

Enable:
sudo ln -s /etc/nginx/sites-available/bioniccomputer /etc/nginx/sites-enabled/
sudo nginx -t
sudo systemctl restart nginx

TROUBLESHOOTING:

Site not loading:
1. Check DNS: nslookup bioniccomputer.com.pk
2. Check firewall: sudo ufw allow 80/tcp
3. Check container: docker ps
4. Check logs: docker logs bionic-web

Chatbot not working:
1. Verify API key is set
2. Check API credits at console.anthropic.com
3. Check logs for errors
4. Test API endpoint directly

Slow performance:
1. Check server resources: free -h, df -h
2. Enable caching
3. Optimize images
4. Add CDN (Cloudflare)
