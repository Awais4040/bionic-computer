🚀 SETUP (3 SIMPLE STEPS):

STEP 1: GET API KEY
  → Go to https://console.anthropic.com/
  → Sign up (free)
  → Create API key (free trial: $5-10 credits)
  → Copy your key (starts with: sk-ant-...)

STEP 2: ADD API KEY
  → Open .env.local file
  → Replace: sk-ant-YOUR_API_KEY_HERE
  → With your actual key
  → Save file

STEP 3: RUN
  → docker build -t bionic-computer:latest .
  → docker run -d -p 3000:3000 -e ANTHROPIC_API_KEY=your_key bionic-computer:latest
  → Visit http://localhost:3000
  → Test the chatbot!
