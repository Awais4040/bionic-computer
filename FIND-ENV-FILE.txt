🔍 HOW TO FIND .env.local FILE

═══════════════════════════════════════════════════════════════════════════════

Your .env.local file is at the ROOT of your project:

📁 Project Structure:
   bionic-computer/
   ├── .env.local                 ← THIS ONE!
   ├── .env.example
   ├── package.json
   ├── Dockerfile
   ├── docker-compose.yml
   ├── src/
   ├── public/
   └── ... other files

═══════════════════════════════════════════════════════════════════════════════

OPTION 1: EDIT WITH TEXT EDITOR (EASIEST)

1. Open your text editor (VSCode, Notepad, etc.)
2. Go to File → Open
3. Navigate to project folder
4. Find and click .env.local
5. It will show:
   
   # Get your API key from: https://console.anthropic.com/
   ANTHROPIC_API_KEY=sk-ant-YOUR_API_KEY_HERE

6. Replace "sk-ant-YOUR_API_KEY_HERE" with your actual key
7. Save (Ctrl+S or Cmd+S)

═══════════════════════════════════════════════════════════════════════════════

OPTION 2: EDIT WITH COMMAND LINE

Run this command to edit:

nano .env.local

OR

cat > .env.local << 'ENVFILE'
# Get your API key from: https://console.anthropic.com/

ANTHROPIC_API_KEY=sk-ant-YOUR_ACTUAL_KEY_HERE
ENVFILE
